<div align='center'>
  <h1>mp3</h1>
  <h3>a very simple CLI wrapper for eyeD3</h3>
</div>

<br><br>

### features
- attach & detach covers from mp3 files
- remove all metadata from an mp3 file

<br><br>

### setup
1. `git clone https://github.com/VillainsRule/mp3 && cd mp3`
2. `bun install`
3. `bun .`
